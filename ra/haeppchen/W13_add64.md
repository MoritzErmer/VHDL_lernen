# W13 · 64-Bit-Addition

6 min · zurück: [W12](W12_kgv.md) · weiter: [W14](W14_atoi.md)

## Ziel
Mit dem Übertrag zwei 32-Bit-Hälften korrekt addieren.

## Erklärung
`add64` addiert `(r1:r2) + (r3:r4)`. `r1`/`r3` sind die oberen, `r2`/`r4` die unteren 32 Bit, das Ergebnis steht in `(r1:r2)`.

`addx rc := rb,ra` liefert **nur** den Übertrag (0 oder 1) der vorzeichenlosen Addition rb + ra.

## Aufgabe
Schreibe `add64`.

<details><summary>Lösung</summary>

```ikr
; V11: add64: (r1:r2) + (r3:r4) -> (r1:r2), r1/r3 = obere 32 Bit, r2/r4 = untere 32 Bit

add64:    addx r5 := r2,r4         ; Uebertrag der unteren Haelfte (0 oder 1)
          add  r2 := r2,r4         ; untere Haelfte
          add  r1 := r1,r3         ; obere Haelfte
          add  r1 := r1,r5         ; plus Uebertrag
          jmp  r31
```
Den Übertrag **vor** der eigentlichen Addition der unteren Hälfte berechnen, sonst ist `r2` schon überschrieben.
</details>

## Klausur
`addx` (Spickzettel), Zweierkomplement (A04).
