# U12 · 2048: Spielfeld zeichnen

12 min · zurück: [U11](U11_lru_test.md) · weiter: [U13](U13_2048_lfsr.md)

## Ziel
Ein Spielfeld per Memory-Mapped I/O in einen Bildspeicher schreiben, mit einer Farbtabelle statt vieler Sprünge.

## Erklärung
Nach **Praktischer Übung 1** (sinngemäß): das Spiel 2048 auf dem IKR RISC II. Das Spielbrett hat 4 × 4 Felder, als Array mit 16 Wörtern ab `board`, zeilenweise. Jedes Wort enthält den **Exponenten** des Steins (Stein 8 = 2³ → 3), 0 heißt leer.

Ein Feld reservierst du mit `board: .skip 16`. Im Simulator liegt es bei `$100`.

**Memory-Mapped I/O**: Die Grafikeinheit hat Adressen im normalen Adressraum, ab `$80000000`. Ein Pixel ist ein 32-Bit-Wort im Format ARGB (`$FFFF0000` = Rot). Beim IKR RISC II ist das genau **ein** `std`/`str` pro Pixel.

Trick: Eine **Farbtabelle** mit einer Farbe pro Exponent. `Farbe = Tabelle[Exponent]` braucht keinen einzigen bedingten Sprung.

Schnittstelle: `draw(r1 = board, r2 = Farbtabelle)`, ein Pixel pro Feld.

## Aufgabe
Schreibe `draw`. Die Basisadresse `$80000000` erzeugst du mit `addhi`.

Startdaten zum Testen (im Editor schon eingetragen, dein Code kommt darunter):
```ikr
.mem $100: 0, 3, 2, 0,  4, 0, 0, 0,  4, 0, 0, 2,  1, 2, 0, 0
.mem $200: $FFCDC1B4, $FFEEE4DA, $FFEDE0C8, $FFF2B179, $FFF59563, $FFF67C5F
```

<details><summary>Lösung</summary>

```ikr
; U12: draw(r1 = board, r2 = Farbtabelle): 4 x 4 Spielfeld in den Bildspeicher ab $80000000
; ein Pixel = ein 32-Bit-Wort, Farbe = Farbtabelle[Exponent]
.mem $100: 0, 3, 2, 0,  4, 0, 0, 0,  4, 0, 0, 2,  1, 2, 0, 0
.mem $200: $FFCDC1B4, $FFEEE4DA, $FFEDE0C8, $FFF2B179, $FFF59563, $FFF67C5F

draw:     addhi r5 := r0,#$8000    ; VRAM-Basisadresse $80000000
          addi r6 := r0,#16        ; 16 Felder
          add  r7 := r0,r0         ; Index
loop:     beq  r6,fertig
          ldr  r8 := (r1,r7)       ; Exponent des Steins
          ldr  r9 := (r2,r8)       ; Farbe aus der Tabelle
          str  (r5,r7) := r9       ; Pixel schreiben
          addi r7 := r7,#1
          addi r6 := r6,#-1
          bra  loop
fertig:   jmp  r31
```
`addhi r5 := r0,#$8000` schreibt die Konstante in die obere Hälfte: `$80000000`. Mit `ldr`/`str` und Index sparst du die Adressrechnung.
</details>

## Klausur
Konstanten erweitern (A05), indizierte Zugriffe (B01).
