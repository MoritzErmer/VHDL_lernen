# U13 · 2048: Zufall ohne Sprünge

10 min · zurück: [U12](U12_2048_draw.md) · weiter: [U14](U14_2048_compact.md)

## Ziel
Einen Pseudozufallsgenerator (LFSR) branchless in Assembler schreiben.

## Erklärung
Neue Steine erscheinen an zufälligen Stellen. Dafür ein linear rückgekoppeltes Schieberegister (wie S09 im VHDL-Teil), in C:

```c
unsigned lfsr() {
    static unsigned r = 1;
    unsigned b = r & 1;
    r = (r >> 1) ^ (-b & 0xc3308398);
    return b;
}
```
`-b` ist bei b = 1 die Maske mit lauter Einsen, bei b = 0 lauter Nullen (C04). So wird das Polynom nur dann eingemischt, wenn eine 1 herausgeschoben wurde – ohne bedingten Sprung.

`r` ist `static`: Es muss **zwischen zwei Aufrufen** erhalten bleiben. Auf dem Stapel ginge das nicht, weil der Stapelbereich nach der Rückkehr freigegeben und vom nächsten Aufruf überschrieben wird. `r` liegt deshalb an einer festen Adresse, hier `$300`.

## Aufgabe
Schreibe `lfsr` (Rückgabe b in `r1`). Die 32-Bit-Konstante baust du mit `addhi` und `addli` zusammen.

Startdaten zum Testen (im Editor schon eingetragen, dein Code kommt darunter):
```ikr
.mem $300: 1
```

<details><summary>Lösung</summary>

```ikr
; U13: lfsr() -> r1 = herausgeschobenes Bit; Zustand r steht fest im Speicher bei $300
; r = (r >> 1) xor (-b and $C3308398), ohne bedingten Sprung
.mem $300: 1

lfsr:     addi r2 := r0,#$300      ; Adresse von r (statisch, nicht auf dem Stapel)
          ldd  r3 := (r2,0)        ; r
          and0i r1 := r3,#1        ; b = r and 1
          lsr  r3 := r3            ; r >> 1
          sub  r4 := r0,r1         ; -b: alle Bits 1, wenn b = 1
          addhi r5 := r0,#$C330
          addli r5 := r5,#$8398    ; Generatorpolynom $C3308398
          and  r4 := r4,r5
          xor  r3 := r3,r4
          std  (r2,0) := r3
          jmp  r31
```
`lsr` (logisch) statt `asr`: Von links muss eine 0 nachrücken, weil `r` vorzeichenlos ist. Die Tests prüfen die ersten Schritte gegen das C-Programm.
</details>

## Klausur
**PÜ1 F4** (warum nicht auf dem Stapel). Branchless mit Masken (C04).
